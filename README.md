# 勘察工具箱（Survey Toolbox）

@LiangMingJian 2026

> 该项目基于 AI 辅助编程，Flutter >= 3.38.5

## 功能介绍

一个适用于项目勘察的工具 APP，提供以下功能：

- 拍照并保存
- 对图片进行批注
- 对图片进行备注
- 导出单张图片
- 导出 Word 文件
